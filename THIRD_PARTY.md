# Annotated text sources

The sentence CSVs and their website exports derive from Universal Dependencies treebanks. The website changes the storage format for browsing; it preserves the annotations stored in the repository. Original source terms continue to apply.

## English EWT

[Universal Dependencies English EWT](https://github.com/UniversalDependencies/UD_English-EWT) derives from the English Web Treebank. Its annotations and database rights are credited to Stanford University and licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The underlying texts retain their original source terms; see the upstream [license and copyright notices](https://github.com/UniversalDependencies/UD_English-EWT/blob/master/README.md#licensecopyright).

## Italian ISDT

[Universal Dependencies Italian ISDT](https://github.com/UniversalDependencies/UD_Italian-ISDT) is credited to Cristina Bosco, Simonetta Montemagni, and Maria Simi. Its resource notice specifies [CC BY-NC-SA 3.0](https://creativecommons.org/licenses/by-nc-sa/3.0/); see the [upstream terms](https://github.com/UniversalDependencies/UD_Italian-ISDT/blob/master/LICENSE.txt) and [ISDT resource page](http://medialab.di.unipi.it/wiki/ISDT/).

Reference: Bosco, C., Montemagni, S., and Simi, M. (2013). *Converting Italian Treebanks: Towards an Italian Stanford Dependency Treebank*. Proceedings of the 7th Linguistic Annotation Workshop & Interoperability with Discourse.

The source CSVs do not record a Universal Dependencies release number. Counts and hashes for the exact files used by the website are included in `docs/assets/site-data.json`.
