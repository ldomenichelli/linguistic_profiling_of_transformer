About the measures

Three views of geometry

IsoScore measures isotropy: how evenly representations occupy their space. Linear ID counts principal components explaining 99% of variance. Nonlinear ID uses the GRIDE estimator.

Each curve describes a group of word representations. It is not a score for an individual word or sentence.

Reading the comparisons

Values and uncertainty intervals come from the saved result tables. Intervals are shown only where the source provides them. Some comparisons exclude sentence-initial words; the affected panels are marked.
