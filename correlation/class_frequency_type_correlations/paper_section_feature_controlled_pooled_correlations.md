### Feature-Controlled Correlation With Class Frequency and Type Count

We tested whether class-level geometric scores were associated with two corpus statistics: class frequency, measured as the number of tokens in the class, and lexical diversity, measured as the number of unique word types in the class. Because the analysis combines heterogeneous linguistic features, we used a feature-controlled pooled correlation. For each model, metric, feature, and class, we first averaged the metric score across all layers, obtaining one layer-mean score per class. We then rank-transformed and z-scored both the layer-mean metric scores and the corpus-statistic values within each linguistic feature separately. These within-feature standardized values were then pooled across POS, token length, token index, dependency head distance, dependency arity, and dependency relation type.

This procedure controls for baseline differences between feature systems. POS classes, length bins, and dependency relations differ in their typical frequencies, type counts, and geometric score ranges. Pooling them directly could estimate a correlation driven by feature identity rather than by variation among classes within each feature. The feature-controlled analysis instead asks whether, within each linguistic feature, classes with higher frequency or higher type count tend to have higher or lower geometric scores. We report Spearman rank correlations on the pooled within-feature standardized values.

After controlling for feature identity, class frequency showed weak and non-significant associations with the geometric metrics. In BERT, the correlations with frequency were small for Isotropy (`rho = -0.152`, `p = 0.245`), Linear ID (`rho = 0.136`, `p = 0.372`), and Nonlinear ID (`rho = -0.054`, `p = 0.685`). GPT-2 showed the same pattern: Isotropy (`rho = -0.181`, `p = 0.166`), Linear ID (`rho = -0.103`, `p = 0.567`), and Nonlinear ID (`rho = -0.060`, `p = 0.649`) were not significantly related to frequency.

In contrast, the number of unique word types was strongly and positively associated with all three families of geometric metrics. In BERT, type count correlated positively with Isotropy (`rho = 0.599`, `p < 0.001`), Linear ID (`rho = 0.860`, `p < 0.001`), and Nonlinear ID (`rho = 0.550`, `p < 0.001`). GPT-2 showed the same qualitative pattern, with positive correlations for Isotropy (`rho = 0.482`, `p < 0.001`), Linear ID (`rho = 0.745`, `p < 0.001`), and Nonlinear ID (`rho = 0.626`, `p < 0.001`).

These results suggest that the observed class-level geometry is more strongly related to lexical diversity than to raw token frequency. Once feature identity is controlled for, frequent classes are not systematically more or less isotropic or intrinsically dimensional. Classes with more unique lexical types, however, tend to occupy geometrically richer or more isotropic regions of representation space, consistently across BERT and GPT-2.
